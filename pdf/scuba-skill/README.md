## 中身のメモ

### No.1 耳抜きやり方３選｜前編（トッティさん）

- 耳抜きのやり方3つ
  - **バルサルバ法**：鼻をつまんで、鼻をかむ要領で息を送る。いちばん多く使われる。「ブスー」「ピー」などの反応があれば成功。反応がなければ、もう少し強めに。
  - **フレンツェル法**：鼻をつまんだまま、舌の奥をグッと上に押し上げる。少しコツがいる。「ピキピキ」と音がすれば成功。
  - **トインビー法**：鼻をつまんで、つばを飲むか、あごを上下左右に動かす。内側から「ピキピキ」で成功。
- 大きく2つに分かれる：強い力＝バルサルバ法／弱い力で手軽＝フレンツェル法・トインビー法
- バルサルバ法
  - 良いところ：強い力で抜けるので、調子の悪い日や、抜けにくい人でも安定する。
  - 気をつけるところ：息を止めて強く力むので、呼吸が乱れやすい。鼻をしっかりつままないと、空気がもれる（「つまみもれ」。マスクの横や上から泡が出る）。
- フレンツェル法・トインビー法
  - 良いところ：手軽。慣れると手を使わずにできる。呼吸が乱れにくい。
  - 気をつけるところ：失敗しやすい。急に深くなったときや、風邪・鼻炎で鼻が詰まっている日は抜けにくい。これしか知らないと、いざというときに困る。
- 耳抜きのしくみ：潜るときにかかる圧力を、内側から押し戻す。

### No.2 耳抜きやり方３選｜後編（トッティさん）

- 初心者・中級者・耳抜きに不安がある人には、**バルサルバ法が圧倒的におすすめ**。
- **耳抜きの「深さ」**という考え方
  - バルサルバ法は強い力で思いっきり抜ける＝例えば「10」抜ける。フレンツェル法・トインビー法は「3」くらい。
  - よくある失敗：しっかり抜けきらないまま（3割くらいで）、だましだまし潜ること。
  - 深く抜いておけば、急に沈んでも余裕（貯金）がある。浅い耳抜きだと間に合わなくなる。
  - 調子が悪い日でも、強い力なら6〜7mぶんは抜ける。
- 耳鼻科の先生のデータ：耳抜きがうまくいかない原因の**9割5分は「やり方が悪い」＝力が足りていない**。力の込め方を直すと、みるみるできるようになる。
- 講習で習うつばを飲む方法も、まちがいではない。ただし浅い耳抜きなので、不安な人・苦手な人には向かない。
- 慣れてきたら：フレンツェル法・トインビー法も練習して、場面で使い分ける（急に深く潜るときはバルサルバ法、など）。
- 耳抜きは「ダイバーの永遠の課題」。焦ると、ますます抜けなくなる。

### No.3〜5 中性浮力（トッティさん。10/14 まーく様：トッティさんでよい）

- 中性浮力＝浮きも沈みもしない状態。肺が風船の役をするので、呼吸で浮き沈みが変わる。
- 練習の基本は**フィンピボット**（つま先を底につけて、うつ伏せ。吸うと浮き、吐くと沈む）。
- できているかの見分け：**吸ったら、ふわっと浮く**。浮くのと沈むのが同じ速さ。
  よくある勘ちがい：吸っても浮かない＝BCDの空気が足りない。少しずつ足す。
- 中性浮力でも、呼吸に合わせてゆるく上下するのが正しい。ぴたりと同じ深さ、ではない。
- 深いところでは、ウェットスーツがつぶれて沈みやすくなる。BCDに少しずつ足して、また「吸ってふわっ」に合わせる。
- 練習の場：潜ってすぐ・集合のとき・安全停止のときなど、足がつく所で、1本につき2回ほど。
- No.5：**下に向かって蹴らない**。体を立てずに、いつも**水平の姿勢**。はじめは底近くでバウンドしてもよい。BCDに少しずつ空気を足して、バウンドを減らす。

### No.8 の学科（中性浮力 PART1〜3・ウエイト PART1〜2）から拾えたこと

- 浮き沈みを決めるのは「重さ」と「体積（肺・BCD・スーツ）」と「姿勢」。
- ダイビング中に体重は変わらない。変えられるのは、BCD・呼吸・姿勢。
- 講習で**泳ぐ姿勢（水平）**で練習するのは、ダイビングのほとんどが泳いでいる時間だから。
- 足が下がった姿勢だと、フィンの力が「上へ」と「前へ」に分かれる。蹴り続けないと浮けず、前にも進まず、砂も巻き上げる。
  → No.5（トッティさん）の「下に蹴らない・水平」と**別の2人が同じことを言っている**。資料の柱にしてよい。
- 浅いところほど、少しの呼吸やBCDの変化で大きく浮き沈みする（圧の変わり方が大きい）。深いほうが安定する。
  → 耳抜きで「潜りはじめが大事」なのと同じ理由。つなげて説明できる。
- ウエイトを変えるのは「器材が変わったとき（スーツ・タンク・BCD）」「海が変わったとき（淡水／海水・深さ）」。
  キロ数の目安はお店の経験則。**数字は書かない。**

### dibee の記事を疑った結果（PADI 公式ブログと照らした）

- 出どころ：https://blog.padi.com/padi-open-water-dives/ （PADI公式。海洋実習4回の中身）
- dibee の一覧は**あらまし**。PADI公式にあって、dibee に無いスキルがたくさんある。
  - マスクに水が全部入ったときのクリア／マスクを外して付け直す
  - 「空気が無い」の合図と、予備の空気源を使いながらの浮上
  - 5つの手順での潜降・浮上（ファイブ・ポイント）、安全停止
  - 口でBCDに給気してのホバリング
  - CESA（緊急スイミングアセント）、ウエイトを捨てる、器材の脱着、足がつったとき、疲れたバディを引く、コンパス、シグナルチューブ、スノーケルとレギュレーターの交換
- dibee の並びでは「潜降と耳抜き」がマスク等のあと。実際には**潜ってから**水中のスキルをする。この並びはそのまま使えない。
- PADI公式の海洋実習の流れ（あらまし）
  - 1本目（〜12m）：潜降、姿勢の確かめ、マスクに少し水が入ったときのクリア、レギュレーターのリカバリーとクリア
  - 2本目（〜12m）：計画、水面で口から給気、5つの手順の潜降、中性浮力、マスクに水が全部入ったときのクリア、予備の空気源と、それを使った浮上、安全停止
  - 3本目（〜18m）：口から給気してホバリング、マスクを外して付け直す
  - 4本目（〜18m）：目印なしで潜降、残りのスキル、ダイビングの組み立て
  - 「どの回でもよい」スキル：足がつったとき・疲れたバディを引く・コンパス・器材の脱着・シグナルチューブ・ウエイトを捨てる・CESA など
- 指導団体（PADI・NAUI・SSI…）で、名前も順番も少しずつちがう。
  → **PADI で受けた**（10/14 まーく様）。講習のお店は**静岡のサンライズ（SunraIZU）**。スキルの名前・順番は **PADI に合わせる**。

## 疑ったところ（一般の安全の考え方と食いちがう点）

- **力の強さ**：一般には「やさしく、早めに、こまめに」が基本。強く力みすぎると、耳の中を傷めるおそれがある。
  → 動画の「強い力」は「力が足りずに抜けていない人が多い」という意味で受けとり、「思いきり」とは書かない。
- **「10mごと」「3mずつ」**：一般には、水面のすぐ下が圧の変わり方がいちばん大きく、**潜りはじめから1mほどごとに**抜くのが基本。
  10mごとに抜く、は資料に書かない。「耳抜きの深さ（10・3）」は**たとえ**としてだけ使う。
- **「9割5分はやり方が悪い（耳鼻科医のデータ）」**：出どころが確かめられない（別の動画で「昔の雑誌の統計」とだけ）。書かない。
- **動画に無いが、入れたい基本**（DAN「Fast Facts」・耳鼻科の学会記事で確かめた）
  - 出どころ：https://world.dan.org/wp-content/uploads/2025/02/Fast-Facts-Guide-Can.pdf ／ https://bulletin.entnet.org/article/scuba-medicine-for-otolaryngologists/
  - 耳抜きの間かくは、出どころで数字がちがう（DAN「はじめの3〜5mは数mごと」、耳鼻科の記事「約50cmごと」）。→ 数字は書かず「潜りはじめから、こまめに」と書く。
  - 足から潜る。潜るロープを使って速さを抑える。
  - 潜る前、水面で一度、やさしく抜けるか確かめる。
  - 痛くなる前に抜く。痛くなったら少し浮上して、もう一度。
  - 鼻が詰まっている日（かぜ・鼻炎）は、無理に潜らない。

## 疑ったところ（中性浮力）

- **No.4 の「浅めの呼吸で上下を抑える」**：はじめ「危ない」と書いたのは言いすぎだった（10/14 まーく様のご指摘）。
  浮き沈みを抑えるための、慣れた人向けの技。動画も「中性浮力がある程度取れる人向け」と断っている。
  気をつけるのは、動画自身も言っている「リラックスしていないと苦しくなる」点。
  → **中性浮力のコントロールの話として、本文に入れる**（10/14 まーく様：「慣れてきたら」ではない）。
    まとめ方：呼吸は浮き沈みの「こまかい調整つまみ」。大きく吸えば大きく浮き沈み、浅めなら小さく。
    基本はゆっくり深く、自分が楽なペース。浮き沈みを抑えたいときは、息の大きさを少し小さくして調整する。
    ※ ただし**息は止めない**（PADI のいちばん大事な決まり）。苦しくなったら、いつもの深い呼吸に戻す。
- 「深いところではBCDに3倍の空気」：根拠が無い数字。書かない（「少しずつ足す」だけ書く）。
- 「1日で8〜9割できる」：お店の宣伝の言葉。書かない。
- 「底に手をついて練習」：砂地・プールに限る。サンゴや生き物の上ではしない、と添える。
- 公式で確かめた点（PADI 日本語ブログ）：ウエイトが合っていること・ゆっくりした呼吸が中性浮力の土台。
  https://blog.padi.com/jp/?p=26880 ／ https://blog.padi.com/jp/?p=26621
