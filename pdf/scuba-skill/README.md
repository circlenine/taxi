## 中身のメモ

### No.1 耳抜きやり方３選｜前編（トッティさん）

- 耳抜きのやり方3つ
  - **バルサルバ法**：鼻をつまんで、鼻をかむ要領で息を送る。いちばん多く使われる。「ブスー」「ピー」などの反応があれば成功。反応がなければ、もう少し強めに。
  - **フレンツェル法**：鼻をつまんだまま、舌の奥をグッと上に押し上げる。少しコツがいる。「ピキピキ」と音がすれば成功。
  - **トインビー法**：鼻をつまんで、つばを飲むか、あごを上下左右に動かす。内側から「ピキピキ」で成功。
- 大きく2つに分かれる：強い力＝バルサルバ法／弱い力で手軽＝フレンツェル法・トインビー法
- バルサルバ法
  - 良いところ：強い力で抜けるので、調子の悪い日や、抜けにくい人でも安定する。
  - 気をつけるところ：息を止めて強く力むので、呼吸が乱れやすい。鼻をしっかりつままないと、空気がもれる（「つまみもれ」。マスクの横や上から泡が出る）。
- フレンツェル法・トインビー法
  - 良いところ：手軽。慣れると手を使わずにできる。呼吸が乱れにくい。
  - 気をつけるところ：失敗しやすい。急に深くなったときや、風邪・鼻炎で鼻が詰まっている日は抜けにくい。これしか知らないと、いざというときに困る。
- 耳抜きのしくみ：潜るときにかかる圧力を、内側から押し戻す。

### No.2 耳抜きやり方３選｜後編（トッティさん）

- 初心者・中級者・耳抜きに不安がある人には、**バルサルバ法が圧倒的におすすめ**。
- **耳抜きの「深さ」**という考え方
  - バルサルバ法は強い力で思いっきり抜ける＝例えば「10」抜ける。フレンツェル法・トインビー法は「3」くらい。
  - よくある失敗：しっかり抜けきらないまま（3割くらいで）、だましだまし潜ること。
  - 深く抜いておけば、急に沈んでも余裕（貯金）がある。浅い耳抜きだと間に合わなくなる。
  - 調子が悪い日でも、強い力なら6〜7mぶんは抜ける。
- 耳鼻科の先生のデータ：耳抜きがうまくいかない原因の**9割5分は「やり方が悪い」＝力が足りていない**。力の込め方を直すと、みるみるできるようになる。
- 講習で習うつばを飲む方法も、まちがいではない。ただし浅い耳抜きなので、不安な人・苦手な人には向かない。
- 慣れてきたら：フレンツェル法・トインビー法も練習して、場面で使い分ける（急に深く潜るときはバルサルバ法、など）。
- 耳抜きは「ダイバーの永遠の課題」。焦ると、ますます抜けなくなる。
