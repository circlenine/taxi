# 器材清掃編（作りはじめ・10/13）

- 名前は「**器材清掃編**」に統一（「器材整理」「機材整理」はややこしいので使わない。10/13 ご指示）。

- 器材準備編とデザイン・きまりは全く同じ（`pdf/DESIGN.md`）。
- **ちがうのは全体の色味だけ**：水色のかわりにパステルオレンジ（準備編と見分けるため）。
- 写真のもと：動画「ダイビング 器材の片付け」（OPEN EV／沖縄県教育委員会）の画面のスクショ。まーく様から受けとり中（10/13 に16枚。続きあり）。
  1. 題「器材の片付け」 2. 器材とバケツ 3.「スキューバ器材の正しい片付け方を学びましょう」
  4.「タンクのバルブを閉めます」 5.「パージボタンを押し ？？？の空気をすべて抜きます」
  6〜9.「ヨークスクリューを外し キャップについた水滴を吹き飛ばします」 10.「キャップを締めます」
  11〜12.「レギュレーターをBCから取り外します」 13. レギュレーターを持つ 14,16.「BCをタンクから外し 水の中でしっかり洗います」 15. レギュレーターを置いたところ
- 字幕の言葉は、準備編と同じ呼び方に言いかえる（タンクのバルブ→タンクくるくる、ヨークスクリュー→銀色金具ぐるぐる、BC→BCD など）。
- 10/13 追加の16枚：17〜18. BCDを水の中で洗う 19.「排気バルブを押しつつ吸気口にホースをつけ 水を入れ BC内部を洗います」
  20. 口で空気を吹きこむ 21.「BCに空気を送り込み 内部に水が行き渡るように回します」 22.「排気バルブ？を下にして水を抜きます」
  23. タンクにキャップ 24.「使用済みのタンクは必ずキャップを外しておきましょう」 25〜28. レギュレーターを流水で洗う（字幕は「寺瀬先生 説明お願いします」＝説明待ちのまま）
  29〜30. レギュレーターを水に沈める 31. 干している部屋 32. 終わりの画面（制作協力 沖縄県立沖縄水産高等学校／著作 沖縄県教育委員会）
