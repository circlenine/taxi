# 資料（PDF）のデザインのきまり

まーくさんから受けた指示を、全部ここにまとめる（2026/10/7〜10/8、スキューバ「機材準備編」で決まったこと）。
**同じデザインで別の資料を作るときは、最初にこれを全部読む。** 新しい指示を受けたら、ここに書き足す。

見本：`pdf/scuba/1_261008_ｽｷｭｰﾊﾞ_機材準備編.pdf`
作り方の道具：`pdf/scuba/tools/`（使い方はいちばん下）

---

## 0. いちばん大事なこと

- 人に共有する資料。社長クラスが見ても恥ずかしくない仕上がりにする。**いい加減は絶対に許されない。**
- 読む人は**初心者**。見るのは**iPhone**。
- **線・角・余白・位置・字の高さは、全部そろえる。** 0.5mm のずれも指摘される。
  - ずれを直したら、**同じずれを見つける検査を足し、わざと戻して NG が出ることを確かめる。**
- 写真の印・切り抜きは、**数字の検査では分からない**。出す前に必ず拡大して目で見る
  （何を囲んでいるか／肝心の物が切れていないか）。
- **どこを囲めばよいか分からないときは、勝手にやらずに先に聞く。**
- 送るたびに、**できなかったこと・確かめられなかったこと**を必ず書く。

## 1. 紙・ページ

- 紙は **A4（210×297mm）**。「スマホで見る」と言われても、紙の大きさは変えない。
- **1項目＝1ページ。多くても2ページ。** ページはなるべく少なく。
- **もくじは必ず1ページに収める。** 行の高さは広めに（押しまちがい防止）。説明文は「もくじ」と同じ行の右。
- ファイル名：`<番号>_YYMMDD_<半角カナの題>_<編>.pdf`（例 `1_261008_ｽｷｭｰﾊﾞ_機材準備編.pdf`）。
  - 日付は**直した日（日本時間）**に必ず合わせる（自動で付ける）。
  - 毎回同じ名前で送るので、iPhone に古い版が残って見まちがえることがある。食いちがったら、まずそれを疑う。

## 2. 文の書き方

- **くだけた言い方**。専門用語はできるだけ避ける（例：ファーストステージ→「銀色金具」）。
  - 正式名称は、名前の下に小さいうすい字で「正式名称：〜」と添える。
  - クイズの**問い**には正式名称を書かない（正式名称クイズの答えになってしまうため）。答えには添えてよい。
  - **名前そのものが正式名称のもの（例：残圧計）には付けない。** 資料にない正式名称を自分で足さない。
- **言葉の途中で改行しない。** 「→」は行の頭に置く（行の終わりに残さない）。
- 最後の行に 1〜3 文字だけ落ちないようにする（行の長さをそろえて折り返す）。
- 本文の文の終わりは「〜るよ」のように、やわらかく（「〜る」で切らない）。手順の題（見出し）は「〜する」のままでよい。
- 題と、すぐ下の大事・補足で同じことを言わない（例：3-2 の題は「タンクの空気を出す」にして、「回しきって半回転戻す」は大事にだけ書く）。
- 写真の下の名前に「赤い丸＝」は付けない（物の名前だけ）。
- 画面の操作は「**タップ**」に統一する（「押す」は使わない。体で押す動作は別）。
- 表記をそろえる（例：「後」に統一／「塊」／「カチカチ」はカタカナ）。半角の（）!?: は使わない。
- 行の頭が「（」「「」のときは、かっこの左の空きを詰めて、下の行と書き出しをそろえる。
- 同じことを2回書かない（例：「全回転で止める！」と「回らなくなるまで回して…」は重複なので片方を消した）。
- ユーザーが打った文は、そのまま使う。打ちまちがいらしいところ（ひらがな／カタカナのゆれ等）は、直したうえで「こう判断した」と伝える。

## 3. 色

- **パステルで統一**（見やすいものだけ）。濃い色の地は使わない。
- 字：#1f2a37／紺 #16466b／うすい字 #6b7785
- 水色：#d7eef9（札・帯）・#a9d8ef（線）・#cfe5f2（区切りの線）・#d4ecfa・#b8def5
- **大事だけ**目立たせる：うすいピンクの地 #ffe3ea ＋ 赤い字 #b4234a（札はピンク2 #ffc4d1）
- 補足の札：水色の地＋紺の字
- 道具の名前は、色の札ではなく「太字＋名前の前の小さな四角」。**この四角だけは、はっきりした色**（どの2色も見分けがつくもの）。
- 決めた色以外は使わない（palette.js で検査）。

## 4. 線・角・字

- 線は**全部 1px**。**二重線は作らない**（8mm 以内に横線が2本並ばない）。**線と文字を重ねない。**
- 角の丸みは **1mm（札）と 2mm（箱・写真）だけ**。
- 字：Noto Sans JP。本文 700、見出し 900。行の高さは**どこも字の大きさの 1.6 倍**。
- 1行目の高さ、同じ行の札の高さ、道具の名前と続く字の下の線（ベースライン）をそろえる。
- 題と中身のすき間は、どの手順も同じ 2.4mm。

## 5. ページの型

- 外側：水色と白の太めのななめ縞のふち＋中に白いカード（角 4mm）。
- 見出し：小さな「工程1 ───」＋大きな題。**右上に魚のイラスト（ページごとにちがう魚）**。
- 道具・工程のページは、見出しの右上に**札の説明**「補足 動画にない話　大事 とくに大事な話」を置く（本文の中には置かない）。
- 表紙：題・副題・「〇〇編」（いちばん大きく）。副題と「〇〇編」のあいだに横線は引かない。
- 下：「※ 講習で教わった内容・インストラクターの指示を最優先に」とページ番号。
- 本文は2列（左右同じ幅・間 7mm）。同じ行の2つの手順は「題・写真・補足」の3段をそろえる（**左右の写真の上下の線がそろう**）。
  - 片方の補足が長く、memo が真ん中に浮くときは、その工程だけ左右の列を上から詰める形にする（工程4）。
- 手順の番号：水色の横長の札（右はしだけ矢印の形）。
- 手順と手順の区切り：水色の横線を1本（補足の最後の行の下には線を引かない）。
- 題が右の列にはみ出さないようにする（はみ出しそうなら題を短くするよう提案する）。

## 6. 補足・大事の札

- **札は1行目に単独で置き、文は2行目から**、欄の幅いっぱいに書く。札の後ろに文を続けない（見栄えが悪い）。
- 札の左はしは、補足（白）も大事（ピンク）も**同じ位置**（左右の余白はどちらも 1.4mm）。
- **同じ札を続けない。** 補足が2つ以上あるときは、札1つの中に段落を分けて書く（あいだは半行）。
- 大事（ピンク）：1行目（見出し）だけ赤い字、2行目からはふつうの紺の字。
- 大事の中の表（例：留める順番）は「番号／場所／やること」の3列。やることが2行になっても書き出しがそろう。

## 7. 写真

- 文字と、写真の大事な部分を重ねない。写真の名前は写真の下に小さく。
- **肝心の物を見切らない**（キャップ・BCD など）。切り抜いたら必ず拡大して確かめる。
- 比べる写真（1-3 の正しい高さ／高すぎ／低すぎ など）は、重ねたとき同じ位置に来るように、同じ倍率・同じ位置で切る。
- ダメな例の写真は、右上に赤い ✕。
- ページの写真の高さは、そのページの中身がちょうど収まる高さに、ページの中で全部同じにそろえる。

### 写真の印（囲み）

- 形は**全部「丸（だ円）」**。動画にもともと描かれている印が丸なので、それに合わせる（四角は使わない）。
- 太さ：**紙の上で約 2.2mm**（2-1 の動画の丸に合わせた）。✕ も同じ太さ（つぶれるなら大きくする）。
- 色：**全部同じ赤 #f93612**（2-1 の動画の丸の色）。動画の丸・矢印の色がちがえば、ぬり直してそろえる。
- 線は、囲む物の**外がわ**に引く（太い線で中身を隠さない）。
- ななめの物（ホース・ベルト・金具）は、**物の向きに合わせて傾けた丸**にする。写真のはしからはみ出さない。
- 囲む場所は、まーくさんにスクショで指してもらった所。分からないときは**先に聞く**。
- 写真の下の名前：「赤い丸＝〜（正式名称：〜）」。

## 8. memo（PDFで書きこめる欄）

- **表紙以外の全ページに、1ページ1つ**。小さく分けず、**1つの大きな塊**にする。
- 工程のページは、左右どちらかの列の空いたところから**ページの下はしまで**（真ん中に浮かせない）。
- 道具・ふり返りのページは、**右上**（題の行から）。左は題と本文。
- 見た目：**うすい黄色の付箋**（#fffaeb）、上のまん中に水色のテープ、右下のすみを折った形、**行ごとに水色の下線**（ノート風）。
  - 水色の紙・黄色のテープなどを試したが、最後は「黄色の付箋＋水色のテープ」に決まった。
- 見出し「memo」の右に小さく「**※タップすると入力**」。
- PDF の文字欄は、ノートの1行に1つ（打った字が線の上に乗る）。
- 足すために、写真を 40mm より低くしない。

## 9. クイズ（PDFで押せる）

- □を押すと答えが出る（もう一度押すと消える）。答えの欄を直接押しても出る。
- 答えの欄は水色の地。ふたは同じ色でふさぐ。
- □の位置は「問題の行のまん中」で測る（行全体のまん中で測ると、✓が下にずれる。10/8 iPhone で起きた）。
- PDF の NeedAppearances は False にする（True だと iPhone が □ の見た目を作り直して ✓ がずれる）。
  出す前に、全部の□に ✓ を入れた版を画像にして、✓ が□の中に入っているか目で見る。

## 9-2. PDF の使い方の説明（表紙）

- iPhone では、memo を書いている間は □ やリンクが効かない（同時には使えない）。PDF の側では直せない。
- 初心者が混乱しないよう、**表紙のもくじの下に「このPDFの使い方」を置く**：
  青い字のリンクで YouTube へ／memo はタップすると書ける／クイズの□で答え（**この順番：YouTube → memo → クイズ。下の注意の並びもそろえる**。各行の左に「どのページで使えるか」の水色の札を付ける：2ページ／2〜10ページ／10ページ）／
  - 「（もう一度タップすると消えるよ）」は、**クイズの□の行**に付ける（□の答えの出し入れの説明だから。10/8 まーくさんと確認）。
  赤い字で次の3行（10/8 ご指示。memo・リンク・クイズ、どれでも起きることとして書く）：
  「YouTubeのリンク、memo、クイズの□／どれかをタップしてる時は、ほかの操作ができない時もあるから／もういいよ！ってなったら右上の「✔︎」をタップすると元に戻るよ」
  - スマホで使う前提の書き方にする（キーボードの【完了】ではなく、iPhone の画面の右上の ✔︎）。

## 9-3. 印刷すると消える説明

- 「タップすると〜」「※タップすると入力」「□を押すと〜」「このPDFの使い方」など、**画面で使うための説明は、印刷では出さない**（10/8 ご指示）。
- しくみ：HTML で `class="scr"` を付ける → 本文の PDF には印刷しない → 同じ見た目の絵を「印刷しない注釈」（/F に 4 を付けない）として同じ場所に重ねる（`scrshot.js`・`addscr.py`）。
- 印刷で使う説明（「補足 動画にない話　大事 とくに大事な話」など）には付けない。
- 確かめ方：`pdftocairo -pdf` で印刷向けに書き出した PDF を画像にして、説明が消えていることを見る。
- 印刷でおかしくなるので、ぼかし（グラデーション）は使わない（memo の折り目が黒くなった）。

## 9-4. もくじのページ移動

- Chrome が書く行き先（名前つき＋座標 XYZ）は、iPhone ではずれて、前のページの途中に着く（10/8 実際に起きた）。
- **行き先は全部 `[ページ /Fit]` に書きかえる**（`fixlinks.py`）。`lnkcheck.py` で、行と行き先のページ番号・形を確かめる。

## 10. 魚のイラスト

- 紺の線 1.6・角は丸く・パステルの色・白い目に紺のひとみ。ページごとにちがう魚（ニモの仲間）。見出しの右上だけに置く。

## 11. 送り方・報告

- 送るたびに PDF をそのまま送る（ファイル名は日付入り）。
- 報告は「・」で並べ、短く。まちがえたときは「申し訳ありませんでした」から始め、何をどうまちがえたか・防げたかを書く。
- できなかったこと・確かめられなかったこと（例：iPhone での memo の入力）を必ず書く。

## 作り方（道具）

`pdf/scuba/tools/` にある。中のパスは作ったときの作業場所（scratchpad）のままなので、使う前に直す。

- `content.py` … 文（手順・クイズ・まとめ）
- `a4.py` … HTML を組み立てる（CSS もここ。下に行くほど新しいきまり）
- `focus.py` … 写真の切り抜き（F）と、印（MARK・MARKR・MARKQ・MARKE）。元の画像はまーくさんの送ってくれたスクショ（リポジトリには入れていない）
- `fish.py` … 魚のイラスト
- `a4make.sh` … 全部まとめて作り、検査をまわし、日付入りのファイル名で書き出す
- 検査：`mcheck.js`（並び・ずれ・二重線・札・memo）、`wrapcheck.js`（改行）、`toccheck2.py`（もくじ）、
  `termcheck.py`（表記ゆれ）、`chipcheck.py`、`palette.js`（色）、`borders.js`（線の太さ）、
  `pairalign.py`（比べる写真）、`pdfimgcheck.sh`、`markreview.py`（印の見直し用の1枚。**目で見る**）
- PDF の部品：`addchk.py`（クイズ）、`addmemo.py` と `memopos.js`（memo）
- 動かすもの：Playwright の Chromium、Python（Pillow・pypdf）、Noto Sans JP
