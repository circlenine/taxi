### 1-4 初心者に関係が深い原因（まとめ）
1. 空気の残りを見ない → 空気切れ（DAN 1位）
2. あわてる（パニック）→ 呼吸が速く浅く → 急に浮上（Morgan、DAN、PADI）
3. 水面での溺れ（エントリー／エキジット。浮力を取っていない）（海上保安庁 2023）
4. 体調不良のまま潜る・心臓・浸漬性肺水腫（海上保安庁 2023、DAN、PADI Japan）
5. はぐれる・流される（海上保安庁 2023、海保 高知の事例）
6. 久しぶり・1本目（DAN）

## 2. PADI が掲げる原則

### 2-1 「安全潜水実施了解声明書」（Standard Safe Diving Practices Statement of Understanding, 10060）◎
講習の最初に署名する10か条。日本語版は「PADI安全潜水実施了解声明書 ver.2.0」（padi.com/ja/forms。本文PDFは今回開けず、英語版で確認）。
1. 心と体を、潜れる状態に保つ。お酒・薬の影響下で潜らない。スキルを保ち、**しばらく潜らなかったら管理された場所で復習**する
2. 知らない場所は、地元の人の案内を受ける。自分の経験より悪い海なら、延期か別の場所に
3. 慣れた、整備された器材を使い、毎回潜る前に点検する
4. ブリーフィングと指示をよく聞く。**6か月以上あいたら、追加の練習をすすめる**
5. **毎回、最初から最後までバディと。** はぐれたときの合流方法・緊急時の手順を、潜る前に決めておく
6. 減圧不要の範囲で、余裕をもって。深さと時間を測る手段を持つ。**最大深度は訓練と経験の範囲内**。
   **浮上は毎分18m以下**（SAFE＝Slowly Ascend From Every dive）。**安全停止は5mで3分以上**
7. 浮力を正しく。水面では浮いて泳ぎ・休む。**重りはすぐ外せるように**。困ったら浮力を確保。水面の合図の道具（笛・フロートなど）を1つ以上持つ
8. **息を止めない・息を飛ばさない（スキップ呼吸しない）**。頑張りすぎない。自分の限界の中で
9. 可能なら、ボート・フロートなど水面の支えを使う
10. 地元の決まりを守る

### 2-2 PADI Japan「ダイバーなら必ず押さえておくべき基本ルール」14項 ◎
息を止めない／計画を立てる／無理をしない／ゆっくり浮上・安全停止（毎分18m以内、5mで3分）／器材チェック（残圧180〜200）／
中性浮力／ひとりで潜らない／ゲージ・コンピューターをこまめに見る／心と体の調子（お酒を飲んだら潜らない・前日よく眠る・
かぜや鼻づまりの日は潜らない）／耳抜きはこまめに（抜けなければ合図→少し浮上→だめなら中止）／
潜ったあとすぐ飛行機に乗らない（18〜24時間以上）／バディチェック（BWRAF）／生き物にさわらない／認定の範囲で潜る

### 2-3 新しく認定されたダイバーへ（PADI ブログ）◎
- **認定後、間をあけずに次を潜る**（いちばん大きな失敗は、スキルを忘れること）
- 上手な人に合わせて急がない。質問をためらわない。写真などは慣れてから（一度にあれこれしない）
- PADI の OW は**最大18m**まで。もっと深くはアドバンスで（SSI も同じ考え）

## 4. 科学的根拠（医学）

| テーマ | 要点 | 強さ・出どころ |
|---|---|---|
| 肺の過膨張（息止め） | 上がるとき肺の空気がふくらむ。息を止めると肺が傷み、空気が血管に入る（エアエンボリズム）ことがある。**息を止めない**が第一の決まり | ◎PADI 基本ルール／○DAN Lung Expansion Injuries |
| 減圧症（DCS） | 体に溶けた窒素が、浮上で泡になる。防ぐのは「減圧不要の範囲」「ゆっくり浮上」「安全停止」。リスク：肥満・心肺の病気・**飲酒・寝不足・脱水**・繰り返し潜水・水中での運動・**寒さ**・潜ったあとの激しい運動・いきみ | ◎PADI 声明／○山見信夫（日本高気圧環境・潜水医学会 小田原セミナー 2024） |
| 浮上の速さ | PADI は「毎分18m以下」。潜水医は「毎分9m以下を推奨、6〜12mは許容」とも。**数字は団体・医師で違う** → 資料には数字を書かず「ゆっくり」が安全 | ◎PADI／○山見 2024 |
| 飛行機・高いところ | DAN：無減圧の1本なら**12時間以上**、何本も・何日もなら**18時間以上**、減圧が要ったら**それより長く**。日本の潜水医：**飛行機・標高600〜2,000mへは18時間以上、300〜600m未満へは6時間以上**。PADI Japan：高い所を通る道で帰るなら、理想は24時間か別の道 | ○DAN Flying After Diving／○山見 2024／◎PADI Japan |
| 耳（圧外傷） | 水面近くがいちばん圧の変化が大きい。早めに・こまめに・やさしく。痛くなる前に。抜けなければ少し上がる。**強く・長くいきまない**（PADI の声明にも「強い・長い耳抜きは耳を傷める」） | ◎PADI フリーダイバー声明・基本ルール／○DAN |
| かぜ・鼻づまり・薬 | 鼻づまりでは耳が抜けにくい。**鼻づまりの薬で乗り切ると、効き目が切れて逆につまる**ことがある | ◎PADI／◎SSI |
| 水分・お酒 | お酒は脱水のもと、脱水は減圧症のリスク。お酒は減圧症の症状を隠す。DAN の分析で、減圧症の人の最大3分の1が潜水の12時間以内に飲酒（2次資料）。**時間の数字は出どころでばらばら** → 「前の日と、潜ったあとはお酒をひかえる」まで | ○DAN（2次資料経由）／◎PADI |
| 睡眠 | 前日はよく眠る。寝不足は減圧症のリスク要因の1つ | ◎PADI 基本ルール／○山見 2024 |
| 寒さ | 寒さは減圧症のリスク要因。ふるえる前に合図して上がる。合ったスーツを | ○山見 2024／◎PADI |
| 潜ったあとの熱いお風呂・マッサージ | 体を急に温めると泡ができやすい（DAN の説明を PADI が紹介）。強いマッサージは12時間ひかえる | ◎PADI Japan（DAN 引用） |
| 二酸化炭素・呼吸のしすぎ | あわてると速く浅い呼吸 → 二酸化炭素がたまり、息苦しさが強まる。「酸素が足りない」ではない。ゆっくり長く吐くのが対策 | ○DAN Your Lungs and Diving（README で確認済み） |
| パニックの体の仕組み | 不安が強い人はパニックを起こしやすく、パニックは事故の大きなきっかけ | ○Morgan 1995・2004、Walton 2018（README で確認済み） |
| 浸漬性肺水腫 | 水に入ると血液が胸に集まり、肺に水がにじむ。中高年・高血圧・冷たい水で起きやすい。**浮上中・安全停止中に強い息苦しさ**。合図して、バディといっしょにゆっくり浮上 | ◎PADI Japan（DAN Japan 会報の引用） |
| 心臓 | 死亡の約4分の1に心臓。60％は前もって症状があった。不調なら潜らない | ○DAN 2012 |
| 生理 | 「潜ってはいけない」「サメが寄る」はどちらも根拠なし。その日の体調で決める | ○DAN（README で確認済み） |

## 5. 経験則：初心者によくある失敗（△が中心。◎があるものは印を付けた）

- 上手な人についていこうと急ぐ（◎PADI）
- 緊張で呼吸が速く、空気がすぐ減る（◎PADI Japan エア消費の記事）
- 重りの付けすぎ → 沈みやすく、BCDに空気を何度も入れる（◎PADI）
- 水中でBCDの給気ボタンを使いすぎる（△SDL）
- 足が下がった姿勢で蹴り続ける・砂を巻き上げる（△専門店／README の動画2本）
- 耳抜きを始めるのが遅い・痛くなってから（◎SSI／△SDL）
- 親指を上で「OK」のつもり → 水中では「浮上」（◎PADI）
- バディチェックを省く・ガイドまかせで残圧を見ない（△SDL／◎SSI）
- 水面で浮力を取らずに疲れる（△SDL／◎海保 2023 の「水面の溺水」）
- 写真に夢中ではぐれる（◎PADI Japan）
- 認定後しばらく潜らずスキルを忘れる（◎PADI）
- バルブを開けたあと「半回転戻す」→ だれかが逆に回して閉まる（○DAN「Tank Valves and Out-of-Air Emergencies」）

## 6. 監査（いまの中身と食いちがう点・足りない点）

### 6-1 食いちがい・根拠が弱いところ

| 場所 | 書いてあること | 問題 | 強さ |
|---|---|---|---|
| 準備編 content.py `CHECK` | 「タンクくるくる、右に半回転戻した？」 | **4-2 の本文は「戻すかどうかはお店のやり方に従ってね」**に直してあるのに、チェック表に古い言い方が残っている。DAN は「半回転戻す」がバルブを閉めてしまう混乱のもとと書き、「全開にしておく」をすすめる | ◎○DAN |
| 準備編 `QUIZ` 役割クイズ | 「タンクくるくるを左に回しきったら？ → 右に半回転戻す」 | 上と同じ。本文と食いちがう | ◎○DAN |
| 準備編 5-3 | 「レギュで、息が吸えるか確かめる」 | **吸いながら残圧計の針が下がらないかを見る**、が抜けている。バルブが開ききっていないと針が呼吸ごとに動く（DAN）。README の「つまずき」表には書いてあるのに本文に無い | ○DAN |
| 準備編 7（バディチェック） | レギュ・オクト・バルブ・残圧・BCDの5つ | PADI の BWRAF にある「重り（W）」と「はずす所＝バックル類（R）」が無い（`CHECK` の「重り、すぐ外せる？」で一部だけ） | ◎PADI |
| スキル編 5-2 | 「レギュのホースを、手で**足もとのほうから**たどる」 | 一般の「手でたどる方法」は、**背中のタンクの首（銀色金具）からホースをたどる**。「足もと」から、は公式・動画で確かめられない。サンライズの教え方なのか、言いかえの誤りか、まーく様に確認を | ◎PADI |
| スキル編 5-2 | 見つからない場合が無い | PADI では、すぐ見つからなければ**オクトパスに切りかえる**のも正しい手（README の rc2 200–290 にもある）。1行あると安心 | ◎PADI |
| スキル編 1-2 | 息苦しい＝あわてたときの流れ、だけ | 息苦しさは、あわて以外に**浸漬性肺水腫**のこともある（PADI Japan「増えている」）。「止まって呼吸しても楽にならなければ、合図してバディとゆっくり上がる」を1-3④に足すと両方に効く。いまの④「合図してダイビングを終える」はほぼ同じ意味なので、**「バディといっしょに、ゆっくり上がる」**と書けば十分 | ◎PADI Japan |
| 洗浄編 6-2 | 「使った器材を、干す」 | 干し方の一言（**直射日光をさけて陰干し**）がメーカー・専門店の定番。安全には直結しないので優先度は低い | ○メーカー（今回は個別に未確認）△ |

### 6-2 足りない大事なこと（あいちゃんがすぐ出会うものだけ）

1. **ゆっくり浮上と安全停止（5mで3分）** ◎PADI 声明・基本ルール
   - スキル編のどこにも無い。アドバンスの深い潜水（OWの18mより深く）で必ずやる。数字は「5mで3分」はPADI共通なので書いてよい。浮上の速さの数字は書かない（団体・医師で違う）。
2. **潜ったあとの過ごし方：飛行機・高いところ・お酒・熱いお風呂** ◎○
   - README の下調べには入っているが、スキル編の本文に無い（p8「これだけは！」の案に入れる予定なら、それで足りる）。
   - **大阪へ車で帰るとき、伊豆なら峠（箱根・伊豆スカイラインなど）を越えることがある**。日本の潜水医の目安（300〜600m は6時間、600m以上は18時間）。数字を出すかは まーく様と相談。「帰り道に高い峠を通るなら、インストラクターさんに相談」で十分。
3. **残圧の「帰りはじめ」を決めておく** ◎DAN・PADI
   - 7-1「こまめに見る」だけ。「お店で決めた数字になったら、ガイドさんに見せて合図」を1行。数字はお店で違うので書かない。
4. **水面では、まず浮く（BCDに空気）** ◎海保 2023（溺水が最多・水面）・PADI 声明7
   - 浮上して水面に出たら、すぐBCDをふくらませる。README の「つまずき」表にあるが本文に無い。
5. **重りを外す（ウエイトの脱着）** ◎PADI Japan
   - PADI Japan によると、**今の PADI OW では「重りを完全に手放す」までが必須スキル**。あいちゃんの講習では していない（まーく様）。
     資料に手順は入れない決まりのままでよいが、「**水面で浮けないときの重りの外し方を、次の講習でインストラクターさんに一度見せてもらおう**」の1行は価値が高い。
6. **体調が悪いときの合図**（PADI の新しい合図） ◎PADI Japan
   - 浸漬性肺水腫・心臓の話とつながる。写真が無いので入れない判断は README どおりでよい。言葉で「何かおかしい」の合図を使う、で代用できている。
7. **はぐれたときの約束を、潜る前にバディと決める** ◎PADI 声明5
   - p3 にケースの対処はある。「潜る前に決めておく」が添えてあればなおよい。
8. **アドバンスでの深い潜水**：OWは18mまで。アドバンスで深く潜るときは、インストラクターについて。窒素酔い（気分がふわっとする）は浅く戻るとおさまる ◎PADI・SSI ／△All About
   - アドバンス用。スキル編に入れるかは まーく様の判断（10ページ以内の決まり）。

## 7. 小学生でもわかる言い方（大事な10こ）

決まり：「危ない」「ダメ」「絶対」「事故」「死」は使わない。ダイビングの専門の言葉（BCD・レギュレーター・残圧計・圧平衡など）も使わない。

| # | 伝えたいこと | 小学生向けのひとこと |
|---|---|---|
| 1 | 息を止めない | 水の中では、「すって・はいて」をずっと続けよう。息を続けていれば、肺がよろこぶよ |
| 2 | ゆっくり浮上 | 上に行くときは、のんびり。エレベーターじゃなくて、ゆっくり階段をのぼる気持ちで |
| 3 | 安全停止 | 上がる前に、浅いところで3分ひと休み。体の中の空気を、そっと外に出す時間だよ |
| 4 | 耳抜き | 耳は、もぐりはじめから早めに、やさしく「ぽん」。いたくなる前がコツ |
| 5 | 空気の量を見る | 空気のメーターは、時計を見るみたいに、ちょこちょこ見よう。たっぷり残っているうちに帰るのが、かっこいいダイバー |
| 6 | バディ | いつも、なかまと手のとどくところで。見えなくなったら、その場でぐるっと見わたして、水の上で会おう |
| 7 | 体調 | 元気な日が、いちばん楽しめる日。鼻がつまっている日や、ねむい日は、おやすみにしよう |
| 8 | 困ったら伝える | こまったら、すぐ手の合図で「ちょっと待って」。早く言えるのが、上手な人 |
| 9 | あわてたら | ドキッとしたら、止まって、ゆっくり長く「ふーっ」とはいて、それから吸おう |
| 10 | 潜ったあと | もぐった日は、飛行機や高い山にはのらずに、のんびり。お水を飲んで、お酒とあついお風呂は、またこんどに |
