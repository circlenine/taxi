## 前提（まーく様に伺ったこと）

- あいちゃんは、ドライスーツが**初めて**。とくに丁寧に、分かりやすく。
- ウェットスーツは、**女性ならではの着やすいコツ**を、YouTube を参考に。
- サンライズで使うドライスーツは、**World Dive「DCD13」「DCD2R」に近い型**と回答をもらった
  （カタログの写真は 10/24 にいただいた。メンズの見本）。
  - ネオプレン（3.5mm）のドライスーツ。表はグロッシーファイバー。
  - 胸に給気バルブ、左肩に排気バルブ（オートテックⅡ）。
  - 背中の肩の線に、防水ファスナー（バックファスナー → 自分では閉められない。バディに閉めてもらう）。
  - 首はソリッドネック（首まわりのシール）。手首もシール。ブーツは一体。
  - ※レンタルの実物で、バルブの位置・ファスナーの向きが同じかは、まだ確かめていない。

### PADI の公式の決まり（10/24 に調べた。資料に出す前に、もう一度確かめる）

- アドバンス：必須のアドベンチャーダイブ＝**ディープ**と**水中ナビゲーション**。ほかに、自分で選ぶ3本（合わせて5本）。
  出典：PADI 公式ブログ（日本語）https://blog.padi.com/jp/padi-advanced-open-water-diver-faqs/
- レスキュー：参加条件＝PADI アドベンチャー・ダイバー以上（ナビゲーションのダイブ済み）＋ **EFR（応急手当の講習）を修了**。最低年齢12歳。
  出典：PADI 公式（日本語）https://padi.com/ja/node/1241
- **まだ確かめていない**：アドバンス後の最大深度（30m／年齢で違う）、EFR の有効期限（24か月以内かどうか）。
  あやしい数字は出さない。サンライズに確かめてから。

### 靴下と裾（まーく様「ピンと来ないので、多くの動画で共通していることを」）
3本の動画が同じことを言っている（ocean_a QtNIOoj7Lp0 2:57／パパラギ 9IG9z5nAkl0 0:56／あおいるか wLkpyktNkhc 1:16）
- 中に着るズボン（レギンス）の裾は、**靴下の中に入れる**
- 靴下は、くるぶし丈ではなく**長め**（ふくらはぎまで）
- なぜ：裾がスーツの中でめくれ上がって、肌がこすれたり、ゴワゴワして不快になる。短い靴下は、ブーツの中で脱げる
- 上の服の裾も、ズボンの中に入れる（パパラギ 1:56／あおいるか 2:01）

### ページごと
1. 表紙・もくじ
2. ウェットとドライの違い・着る前の準備
   - ウェット：中に水が入り、体温で温まる。ぴったりのサイズが暖かい（パパラギ LCOT_-MAkq0 0:52）
   - ドライ：水が入らない。中に服を着る。スーツの中の空気で温かい
   - 中に着るもの：ウェットは水着＋インナー（ocean_a vljgA5VqNPE）／ドライは上の「靴下と裾」
   - 着る前に：トイレに行く（ドライは脱ぐのが大変）・髪をまとめる・指輪とネイル（シールやスーツを傷める）
   - 寒い日：フード・手袋
3. ウェット：着方（女性のコツ）
   - 腰から下を半分に裏返す（DIVER mag DwV0Abnrm9s 0:16）
   - 足の甲を伸ばして入れ、かかとを持ってクイッ（DIVER mag 1:12・パパラギ LCOT 2:36）
   - 膝のパッドを膝に合わせる（DIVER mag 1:35）
   - 一気に引っ張らず、少しずつ上げる（ROXY 8eup5ULd8_U 1:21）
   - 爪で引っ張らず、指の腹でつまむ（ROXY 2:28・パパラギ LCOT 2:54）
4. ウェット：脱ぎ方
5. ドライ：各部の名前と、着る前の点検
   - 胸＝空気を入れるボタン／左肩（または手首）＝空気を抜くボタン／背中＝防水ファスナー／首と手首＝ゴムのシール／サスペンダー／ブーツ
   - 点検：シールが薄くなっていないか・ファスナーが動くか・ボタンが戻るか（ocean_a 0:37）
6. ドライ：着方
   - 膝まで裏返してから足を入れる（ocean_a 2:19）
   - サスペンダーを、ねじらず左右1本ずつ（パパラギ 2:19）
   - 手首：「萌え袖」で通し、爪を立てない。手首の骨まで（パパラギ 4:14）
   - 首：親指で広げすぎず、軽くおじぎして通す。髪を出す（パパラギ 5:06・ocean_a 4:33）
   - **首のゴムを内側に折る**（忘れると水が入る）（ocean_a 4:53）
   - 腕を大きく広げて、背中のファスナーはバディに。最後に自分で引っ張って確かめる（パパラギ 7:14）
7. ドライ：水の中での使い方
   - 器材を背負う前に、しゃがんでスーツの中の空気を抜く（パパラギ NS8OkAwcAJc 2:13）
   - 器材は左肩から（排気ボタンが引っかかる）（熱烈 dxS0lvGebBA 0:36）
   - 空気を入れるホースは、脇の下から通してつなぐ（熱烈 1:04）
   - 浮き沈みは BCD で。ドライに空気を入れるのは「きつい・寒い」ときだけ（パパラギ NS8OkAwcAJc 0:00・1:00）
   - 重りが増える
   - 足が浮いてしまったら（吹き上げ）：（マリンダイビング 6tkqVLBOEpA。文字起こしなし。中身を確かめてから）
8. ドライ：脱ぎ方と後片付け
   - 着たまま水で洗う。ファスナーは念入りに。ボタンは押しっぱなしにしない（ocean_a 5:46）
   - 首：前かがみで、あごから抜く。爪を立てない。無理ならバディに（パパラギ 9:24・ocean_a 6:16）
   - 手首：指を深く入れて、手をすぼめてくるくる（パパラギ 12:09）
   - 足：サスペンダーを外し、膝下まで下ろしてから。靴を近くに置く（パパラギ 13:51）
9. 集約版
