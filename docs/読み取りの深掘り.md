# 読み取れているかを確かめる手順

「ニューオータニとワントゥワンは、ちゃんと読めているのか」を
自分の目で確かめるための手順です。iPhoneだけでできます。

---

## 先に知っておいてほしいこと

この2つは、ほかの会場と作りが違います。

| 会場 | 一覧のページ | 日にち・時刻の在りか |
|---|---|---|
| 大阪城ホールなど | 日付が載っている | 一覧のページ |
| **ホテルニューオータニ大阪** | 催しの名前だけ | **中のページ** |
| **ワントゥワン** | 公演名だけ | **中のページ** |

つまりこの2つは、**一覧に日付が無いのが正しい姿**です。
[9] でこれまで ⚠️ が出ていたのは、こちらの出し方が悪かったためで、
読めていないという意味ではありませんでした。**U098で直しました。**

---

## 手順

### ① まず [9] で、実際に読ませてみる

記録用スプシの「説明」タブ → **[9] イベント情報を調べる** に☑を入れる。
結果が、まーくさん個人のLINEに届きます。

会場ごとに、こう出ます。

```
■ ホテルニューオータニ大阪（event）
　返事：200 ／ 大きさ：148KB
　ℹ️ 一覧のページに日付はありません（この会場は、それでふつうです）
　　中のページまで開いて読む作りにしてあります。
　✅ 実際に読ませてみた結果：4日ぶんで 2件
　　読めた中身（ホームページと見くらべてください）
　　9/22　〇〇の会　開演11:00〜14:00（予想）
```

**見るところは、いちばん下の「実際に読ませてみた結果」です。**
上の「返事：200」は「ページが開けた」だけで、読めた意味ではありません。

| 出かた | 意味 |
|---|---|
| ✅ ◯件 | 読めています。中身を次の②で見くらべる |
| ❌ 0件 | 読めていません。③へ |

### ② ホームページと、自分の目で見くらべる

[9] の結果に出た「読めた中身」と、実物を見くらべます。

- ニューオータニ　https://www.newotani.co.jp/osaka/
- ワントゥワン　　https://onetoone-jp.com/schedule.php

**見るのは3つだけです。**

1. その日に催しが出ているのに、[9] に出ていないものはないか
2. 公演名が、途中で切れたり化けたりしていないか
3. 時刻が合っているか（**開場と開演を取りちがえていないか**）

3つめが、いちばん間違えやすいところです。
[9] の結果には `開演18:00` `開場17:00` と、どちらか書いてあります。
**「開場」と出ているのに実際は開演だった**、という取りちがえがないか見てください。

### ③ 0件だったとき、または中身が合わないとき

**LINEで「📒」と送ります。**

読み取り台帳（まーくさん専用のスプシ）が作られて、
**会場ごとの件数**と、**1件ごとに なぜ出なかったのか**が並びます。

```
📋 会場ごとの件数（⚠️＝0件。無いか、読めていないか）
　大阪城ホール：12件
　⚠️ ホテルニューオータニ大阪：0件
　ワントゥワン：3件
```

台帳の1行ごとに、こう書いてあります。

| 書いてあること | 意味 |
|---|---|
| 時刻が読み取れていない | 拾えてはいるが、時間が分からない |
| 時間帯の外（早すぎる／遅すぎる） | 拾えている。営業時間の外なので出していないだけ |
| 見込み人数が 100人 未満 | 拾えている。小さすぎるので出していないだけ |
| （空白） | ちゃんと出している |

**ここが肝心です。** 「0件」には2つの意味があります。

- **ほんとうに催しが無い**（ホテルの宴会は、載らない日も多い）
- **ページの作りが変わって、読めなくなった**

見分け方は、**②でホームページを開いて、催しがあるかどうかを見る**しかありません。
催しが出ているのに0件なら、読めなくなっています。

### ④ 読めなくなっていたら、こちらに伝える

そのまま言ってもらえれば直します。伝えてほしいのは、この3つです。

1. どの会場か
2. ホームページに出ている催しの名前と日時（1つでかまいません）
3. [9] の結果の、その会場のところ（スクショで結構です）

---

## 紙の資料（帝国ホテル・リーガロイヤル）

この2つはホームページに出ていません。写真を送って読み取っています。
読み取ったものを見返すには、**LINEで「📄」** と送ってください。
置き場と、資料の一覧が出ます。

---

## どれくらいの頻度で見ればいいか

**月に1回で十分です。** ページの作りは、そう頻繁には変わりません。

ただし、次のときは その場で ① をやってください。

- イベント通知に、いつも出ている会場が出てこなくなった
- 出ている時刻が、明らかにおかしい

---

## 絵文字のまとめ（この確認で使うもの）

| 絵文字 | 出るもの |
|---|---|
| 📒 | 読み取り台帳（会場ごとの件数・出なかった理由） |
| 📄 | 紙（写真）の資料の置き場 |
| 📅 | 今日のイベント一覧 |
| 🎪 | イベント通知の確認用（日を選んで出す） |
| ❗ | 版が満杯のときの直し方 |
| ❓ | 絵文字の一覧 |

※ [9] だけは、記録用スプシの「説明」タブのボタンです。
　 ページを実際に読みにいくので、時間がかかるためです。
