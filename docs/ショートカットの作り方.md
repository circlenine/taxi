# iPhoneの「リマインダー」に入れるショートカットの作り方

イベント通知のLINEに出る【 リマインダー】ボタンを、押すだけで
iPhoneの「リマインダー」アプリに入るようにするための用意です。

**作るのは、まーくさんが1回だけ。** そのあと、みんなは入れるだけです。

---

## 先に知っておいてほしいこと

iPhoneの「リマインダー」に、外から直接 書き入れる入り口を
Appleは出していません。こちらの作り方の問題ではありません。
唯一の道が「ショートカット」アプリです。

**「ショートカット」は、iPhoneに最初から入っているアプリです。**
消してしまっていたら、App Store で「ショートカット」と検索すれば
無料で戻せます（作ったのは Apple です）。

**作業時間の目安：10分。** パソコンは要りません。iPhoneだけでできます。

---

## 第1部　ショートカットを作る（まーくさんが1回だけ）

### ① 「ショートカット」アプリを開く

ホーム画面で、下にスワイプして「ショートカット」と打つと出てきます。
アイコンは、紫とピンクの四角が2つ重なった絵です。

### ② 右上の「＋」を押す

「新規ショートカット」という画面になります。

### ③ 真ん中の検索らんに「テキスト」と打つ

候補の中から **「テキスト」** を選びます。
（「テキストを表示」「テキストと一致」ではありません。ただの「テキスト」です）

画面に、空っぽの入力らんが1つ置かれます。

### ④ その入力らんをタップして、変数を入れる

入力らんをタップすると、キーボードの上に細いバーが出ます。
そのバーの中の **「ショートカットの入力」** を押します。

入力らんに **「ショートカットの入力」** と青い文字で入れば成功です。

> **つまずきやすいところ**
> 「ショートカットの入力」がバーに出ないときは、
> 1つ下の ⑤ まで進めてから、もう一度ここに戻ってください。
> 動作が2つ以上ないと、変数の候補が出ないことがあります。

### ⑤ 下の検索らんに「一致するテキスト」と打つ

候補から **「テキストと一致」** を選びます。

「正規表現」のらんに、次の1文字だけを打ちます。

```
｜
```

**これは全角の縦棒です。** 「|」（半角）ではありません。
iPhoneのキーボードで「たてぼう」と打つと変換候補に出ます。

そして「テキスト」のらんには、④で作った **「テキスト」** を入れます。
（らんをタップ → バーから「テキスト」を選ぶ）

### ⑥ さらに下に「テキストを分割」を足す

検索らんに「分割」と打って、**「テキストを分割」** を選びます。

- 「テキスト」のらん　→ ④で作った **「テキスト」**
- 「区切り」のらん　　→ タップして **「カスタム」** を選び、`｜`（全角の縦棒）を打つ

### ⑦ 「リストから項目を取得」を2つ足す

検索らんに「項目を取得」と打って、**「リストから項目を取得」** を選びます。

**1つめ（件名になります）**
- 「リスト」　→ ⑥の **「分割されたテキスト」**
- 「取得」　　→ **「最初の項目」**

もう一度 同じものを足します。

**2つめ（日時になります）**
- 「リスト」　→ ⑥の **「分割されたテキスト」**
- 「取得」　　→ **「最後の項目」**

### ⑧ 「テキストから日付を取得」を足す

検索らんに「日付を取得」と打って、**「テキストから日付を取得」** を選びます。

「テキスト」のらんに、⑦の **2つめ**（最後の項目）を入れます。

### ⑨ 「リマインダーを追加」を足す

検索らんに「リマインダー」と打って、**「リマインダーを追加」** を選びます。

- 「タイトル」　→ ⑦の **1つめ**（最初の項目）
- 青い文字の **「表示を増やす”」** を押して、次を設定します
  - 「期限」を **オン**
  - 期限の日時　→ ⑧の **「日付」**

### ⑩ 名前を付ける

いちばん上の「新規ショートカット」という文字を押して、
名前を次のとおりに打ちます。

```
タクシーのリマインダー
```

**この名前は、1文字でも違うと動きません。**
ひらがな・漢字・送り仮名まで、そのまま写してください。

右上の **「完了」** を押します。

---

## 第2部　ちゃんと動くか、その場で確かめる

作ったショートカットを開いて、右下の **▶︎（再生）** を押します。

はじめて動かすときは、
**「”ショートカット”がリマインダーへのアクセスを求めています」**
と聞かれます。**「許可」** を押してください。
ここで「許可しない」を押すと、以後ずっと何も起きません。

▶︎ で動かすと、入力が空っぽなので、リマインダーは作られないか、
題の無いものが1つできます。それで正常です。できたものは消してください。

**本番の確かめ方**は、第4部でやります。

---

## 第3部　こちらに名前を覚えさせる

公式LINEの **1対1のトーク**（グループではありません）で、次を送ります。

```
ショートカット タクシーのリマインダー
```

こう返ってきたら、覚えました。

```
📲 ショートカットの名前を覚えました。
　「タクシーのリマインダー」
```

いま何を覚えているか見たいときは、`ショートカット` とだけ送ってください。

> **なぜ名前を覚えさせるのか**
> 名前が分からないと、押しても何も起きないボタンを出すことになります。
> 押しても何も起きないリンクを渡すのが、いちばん不親切だからです。
> だから、名前が決まるまでボタンは出さない作りにしてあります。

---

## 第4部　本番で確かめる

1. LINEで **「🎪」** と送る
2. カレンダーが出るので、**イベントがある日**を選ぶ
3. **【OK】** を押す
4. 届いたイベントの絵の中の **【 リマインダー】** を押す
5. 「”このWebサイト”で”ショートカット”を開きますか？」と聞かれたら **「開く」**
6. ショートカットが一瞬動いて、リマインダーに入ります
7. **「リマインダー」アプリを開いて、入っているか目で確かめる**

題は「大阪城ホール　〇〇（公演名）」、期限は終了予定の5分前になります。

---

## 第5部　みんなに配る

### ① 配る用のリンクを作る

「ショートカット」アプリで、作ったショートカットを長押し
→ **「共有」** → **「iCloudリンクをコピー」**

`https://www.icloud.com/shortcuts/……` という形のリンクがコピーされます。

### ② こちらに覚えさせる

公式LINEの1対1で、コピーしたリンクをそのまま送ります。

```
ショートカット https://www.icloud.com/shortcuts/xxxxxxxx
```

### ③ グループに配る

そのリンクをグループLINEに貼って、次のように伝えてください。

> このリンクを押して「ショートカットを追加」を押してください。
> 1回入れるだけで、あとはイベント通知の【リマインダー】を
> 押すだけで、自分のiPhoneのリマインダーに入ります。
> **名前は変えないでください。** 変えると動きません。

## つまずいたときに見るところ

| 起きていること | 見るところ |
|---|---|
| ボタンを押しても何も起きない | ショートカットの名前が `タクシーのリマインダー` と1文字も違わないか |
| 「ショートカットが見つかりません」と出る | その人のiPhoneに入っていない。第5部のリンクをもう一度 |
| リマインダーは開くが、何も入らない | 第2部の「許可」を押していない。設定 → ショートカット → リマインダー をオン |
| 時刻がおかしい | 第1部⑧の「テキストから日付を取得」に、⑦の**2つめ**（最後の項目）が入っているか |
| 題が「大阪城ホール｜2026年…」と全部入ってしまう | 第1部⑥の区切りが全角の `｜` になっているか（半角の `|` ではない） |
| そもそも【リマインダー】ボタンが出ない | 第3部がまだ。`ショートカット` と送って確かめる |

---

## 中で何が起きているか（知らなくても使えます）

こちらからは、次の1本の文字を渡しているだけです。

```
大阪城ホール　〇〇ライブ｜2026年9月18日 20:55
```

ショートカットの側で、これを `｜` で2つに切って、
前を「題」、後ろを「日時」にしています。
形をかんたんにしてあるほど、こわれにくいからです。

日時を「2026年9月18日」と日本語で渡しているのも、わざとです。
`2026-09-18` の形だと、機種や設定によって月と日を逆に読むことがあります。
