# 版（バージョン）が満杯になったら

LINEにこう出たときの手順です。

```
《じどう》 ⚠️ 公開だけ しっぱい
C059/E005/L058/W011/*U098/V051/T003
コードは入りました。LINEの受け口だけ古いままです。
原因：版（バージョン）が200こで満杯
直し方：LINEで「❗」と送ってください
```

---

## 何が起きているか

Apps Script は、1つのプロジェクトに **版を200個まで**しか持てません。
コードを取り込むたびに版が1つ増えるので、直しを重ねると必ずいつか当たります。

**大事なのはここです。満杯でも、コードそのものは入っています。**

| 動くもの | 新しいコード？ |
|---|---|
| 記録用スプシのボタン（[1]〜[14]） | ✅ 新しい |
| 見張り（トリガー）でひとりでに動くもの | ✅ 新しい |
| **LINEの受け口（公式LINEに送ったとき）** | ❌ **古いまま** |
| **みんなの記録ページ** | ❌ **古いまま** |

「コードを入れ替えたのに、LINEだけ前のまま」は、これが原因です。
黙って古いまま動くので、いちばん気づきにくい形です。

---

## ① まず試すこと（LINEだけでできます）

### 1. 「❗」と送る

いまの状態が出ます。

```
❗ 版（バージョン）が満杯のとき
版：200 ／ 200　デプロイ：14
```

### 2. 「❗そうじ」と送る

**この1回目では、まだ何も触りません。** 何をするかが出るだけです。

```
❗ 古いデプロイの片づけ（まだ何もしていません）
デプロイの数：14　版の数：200
片づける数：10（古い順）
　2026/03/02 〜 2026/08/11 のぶん
残すもの：使用中／作業中／新しい方／新しい方／新しい方
```

**「残すもの」に「使用中」が入っているか、必ず確かめてください。**
これは、いまLINEとみんなの記録ページが使っているものです。
これだけは絶対に触らない作りにしてありますが、目でも確かめてください。

### 3. 中身を見て、よければ3分以内にもう一度「❗そうじ」

```
❗ 片づけました
デプロイ：10件（しくじり 0件）
版の数：200 → 200
版は減りませんでした。デプロイと版は別ものでした。
```

### 4. 「💩」と送って、取り込み直す

版が減っていれば、これで直ります。

---

## ② 版が減らなかったときは

**正直にお伝えします。** 版を消す入り口を、Googleは出していません。
（作る・見る はありますが、消すはありません）
デプロイを片づけても版が減らないのは、そういう理由です。

そのときは、**プロジェクトを作り直す**しかありません。
やることが多いので、**必ず声をかけてください。付き添います。**

作り直しでは、次のものが変わります。何も知らずに1人でやると、
LINEが完全に止まります。

| 変わるもの | やり直しが要ること |
|---|---|
| スクリプトID | — |
| **ウェブアプリのURL** | **公式LINEのWebhook URLの貼り替え** |
| | みんなの記録ページのURLの配り直し |
| 見張り（トリガー） | 全部 立て直し |
| スクリプトプロパティ | 鍵（LINEトークン・Geminiキーなど）の入れ直し |

---

## ③ 次は満杯にしないために

版が180をこえると、取り込みの知らせに1行だけ警告が出ます。

```
《じどう》 とりこみ かんりょう（1件）
C059/E005/L058/W011/*U098/V051/T003
⚠️ 版 185/200（満杯が近い→「❗」）
```

これが出たら、**満杯になる前に**「❗そうじ」をしてください。
満杯になってから気づくと、その間ずっと
LINEの受け口だけが古いまま動きます。

---

## なぜ2回に分けているのか

消したものは戻りません。
1回目に「何をするか」を見せて、2回目で実行します。
3分たつと、また1回目からやり直しになります。

**使用中のものには、どちらの回でも手を出しません。**
無くすと、LINEが完全に無反応になり、URLも配り直しになるからです。

**並べる順は「更新した日付」です。版の番号は使っていません。**
番号は付け直しや作り直しで前後することがあり、
古いつもりで新しいものを消してしまうためです。
