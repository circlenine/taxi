つけ待ち台帳

使い方マニュアル

毎晩の入力から、グラフの読み方、人の追加・削除まで。セットアップが終わったあとに読むものです。

まず、スマホで開けるようにする

公開URLをスマホのブラウザで開き、ホーム画面に追加しておくと、アプリと同じように1タップで開けます。

iPhoneSafariで開く → 下の共有ボタン（四角に上矢印）→「ホーム画面に追加」
AndroidChromeで開く → 右上の︙ →「ホーム画面に追加」
ログインは入れっぱなしで大丈夫一度ログインすれば、しばらく入力を求められません。車内で素早く記録するためのものなので、毎回ログインする必要はありません。

毎晩やること

1回の乗務が終わるたびに、4つだけ入れます。信号待ちでも10秒で終わるのが狙いです。

入れるもの補足
つけ待ち場所一度入れた場所はボタンで出てくるので、2回目からはタップだけ。
乗せた時刻2530 25:30 1:30 どれでも通る。深夜1時半は25:30でも1:30でも同じ扱い。
待ち時間（分）つけてから出発するまで。5分・10分などのボタンあり。
乗車時間（分）乗せてから降ろすまで。
金額メーターの金額。
日付は「夜が始まった日」深夜2時に入力しても、その夜の始まりの日付のままにします。朝6時までは自動で前日の日付が入るようになっています。

グラフの読み方

いちばん大事な数字「時間単価」

金額 ÷（待ち時間 ＋ 乗車時間）× 60 で出した、1時間あたりの実入りです。つけ待ちで潰した時間も込みで計算しています。

なぜ金額だけで見てはいけないか

ケース金額かかった時間時間単価
長距離を1本¥24,070待ち12分＋乗車82分¥15,364/h
近場をちょこちょこ¥1,000待ち5分＋乗車7分¥5,000/h
待たされた末の近場¥3,400待ち30分＋乗車16分¥4,435/h

金額が3倍違っても、時間単価では逆転することがあります。「どこで何時に待つか」を決めるのは、金額ではなくこちらの数字です。

4つの見方

タブ何が分かるか
熱いところ時間帯×場所のマス目。濃いマスほど割がいい。今夜どこで待つかを決める画面。3件以上たまったマスだけ信じること。
一夜の流れ夜ごとの帯グラフ。細い線が待ち、太い帯が実車。空白が長い夜は、流しに切り替えるかつけ場所を変える余地があった夜。
時間×金額これまでのスプレッドシートと同じ形のグラフ。金額のラベルは自動で重ならない位置に逃げる。
集計時間帯別・場所別のランキング。平均の待ち時間も出る。薄い棒は件数が足りていない印。
「自分だけ／全員」の切り替えどのタブにもあります。自分の成績を見るときは「自分だけ」、場所の良し悪しを判断するときは3人ぶんのデータが集まる「全員」が当てになります。

管理画面でできること

右上の 管理 から入ります。

やりたいことやり方
表示名を変える「自分の設定」の表示名を書き換えて保存。台帳の「記録者」欄に出る名前です。
パスワードを変える「パスワードを変える」に2回入力して保存。仮パスワードのままにしないこと。
誰がどれだけ記録しているか見る（管理者のみ）「使っている人」の表。件数・売上・時間単価・最後の記録日が出ます。
全員のデータを書き出す（管理者のみ）「全部CSVで書き出す」。月末の集計や、控えを残すときに。

新しいドライバーを増やす

安全のため、台帳の画面からはアカウントを作れません。Supabaseで作ります（1分）。

  1. Supabase → Authentication → Users
  2. 右上 Add user → Create new user
  3. メールアドレスと仮パスワードを入れ、Auto Confirm User にチェック
  4. Create user を押す
  5. 本人に「公開URL・メールアドレス・仮パスワード」を伝え、初回ログイン後すぐに管理画面でパスワードを変えてもらう

辞めた人を消す

先にCSVを書き出してから Supabase → Authentication → Users でその人を削除すると、その人が入力した記録もまとめて消えます。 売上の記録を残しておきたいなら、消す前に管理画面の「全部CSVで書き出す」を実行してください。

お金とバックアップ

Supabase無料。データ500MBまで。この使い方なら10年たっても埋まりません。7日間アクセスがないと一時停止（ボタン1つで復活、データは無事）。
Vercel無料。月100GBの通信まで。3人で使うぶんには届きません。
月に一度の習慣 管理画面から「全部CSVで書き出す」を実行して、スプレッドシートかパソコンに保存してください。 サービス側の障害や、うっかり削除から守る唯一の方法です。1分で終わります。
勝手に課金されることはありません 有料に切り替わるときは必ずクレジットカードの入力を求められます。カードを登録しない限り、請求は発生しません。 「上限に達しました」というメールが来たら、無視せず転送してください。

アプリを直したくなったら

使っているうちに「ここをこう変えたい」が出てきたら、連絡をください。直したファイルをお渡しするので、次の手順で反映できます。

  1. GitHubの tsukemachi を開く
  2. 差し替えるファイル名をクリック → 鉛筆アイコン → 中身を全部消して、新しい中身を貼る
  3. Commit changes を押す
  4. 1〜2分で、公開URLに自動的に反映される
記録は消えませんアプリの見た目や機能を差し替えても、Supabaseに入っている記録はそのままです。入れ物を替えるだけで、中身は触りません。
