セットアップ中に起きること

こうなったたぶん原因直し方
画面が「読み込んでいます…」から進まない config.js の2行が正しくない GitHubで config.js を開き直し、URLとキーを貼り直す。URLの最後に / が付いていないか、ダブルクォートが消えていないかを確認。直して Commit changes すると1分ほどで自動的に反映される。
公開URLを開くと「404」と出る GitHubにフォルダごとアップロードした GitHubのトップ画面に index.html が直接並んでいるか確認。アプリ本体 というフォルダが1個あるだけなら、手順書の2番をやり直す。
SQLを実行したら赤い文字が出た 貼り付けが途中で切れている schema.sql をもう一度メモ帳で開き、Ctrl + A で全選択してから貼り直す。何度実行しても壊れない作りなので、そのまま再実行してよい。
作ったアカウントでログインできない Auto Confirm User のチェックを忘れた Supabase → Authentication → Users でその人を削除し、チェックを入れて作り直す。
記録ボタンを押すと「保存できませんでした」 手順1のSQLが最後まで通っていない SQL Editorで schema.sql を丸ごと貼り直して Run。それでも出るなら連絡を。
Vercelのリポジトリ一覧に出てこない GitHubとの連携が未許可 Import画面の Adjust GitHub App Permissions から tsukemachi を選んで許可する。

使っていて起きること

こうなったたぶん原因直し方
パスワード再設定のメールが来ない 迷惑メールに入っている／短時間に送りすぎ まず迷惑メールフォルダを見る。メールは1時間に数通までという制限があるので、連打すると届かなくなる。急ぐなら管理者が Supabase → Authentication → Users からその人を選び、パスワードを直接上書きするのが早い。
再設定メールのリンクを押したらエラー Redirect URL が未登録 手順書の5番をやる。https://〇〇.vercel.app/login を Redirect URLs に追加。
久しぶりに開いたら繋がらない Supabaseが一時停止している 無料プランは7日間アクセスがないと自動で止まります。Supabaseにログインして Restore を押せば戻る。データは消えません。毎晩使っていれば止まりません。
自分の記録に「直す・消す」が出ない 別のアカウントでログインしている 右上の名前を確認。違う人でログインしていたらログアウトして入り直す。
他人の記録を消したい 管理者権限がない 管理者だけが他人の記録を消せます。管理者本人に頼むか、手順書7-2のSQLで管理者を増やす。
グラフが真っ白 その絞り込みに記録がない 「自分だけ」になっていないか確認し、「全員」に戻す。
スマホで表が切れる 横に長い表 表の上で横にスワイプすると続きが見えます。
