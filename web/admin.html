自分の設定

名前は2つあります。どちらも、いつでも自分で変えられます。
短い名前… 記録の「記録者」欄や、一覧に出る名前。
称号… この画面の右上、自分の名前のところに出るもの。空でもかまいません。

パスワードを変える

6文字以上。変えたあともログインは続きます。

使っている人

記録の件数と売上は、その人が自分で入れたぶんだけを数えています。

フィードバック

みなさんが【フィードバック】から送ったものが、新しい順に出ます。 直し終わったら【済み】を押してください。押すと、下へ下がります。

新しいドライバーを追加する

安全のため、この画面からはアカウントを作れません。Supabaseの管理画面で作ります（1分）。

  1. Supabase → 左メニュー Authentication → Users
  2. 右上の Add user → Create new user
  3. メールアドレスと仮のパスワードを入れ、Auto Confirm User に必ずチェック
  4. Create user を押す
  5. 本人に「このURL・このメール・この仮パスワード」を伝え、初回ログイン後にこの画面でパスワードを変えてもらう

やめた人を消すときは、同じ Users の画面でその行を削除します。その人の記録もまとめて消えます。残したいなら先に台帳からCSVを書き出してください。

全データの書き出し

全員ぶんの記録をCSVで。月末の集計や、万一のときの控えに。

アカウントの追加・削除は Supabase の管理画面から。この台帳からは操作できません。
