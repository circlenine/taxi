# つけ待ち台帳（ウェブのアプリ）

ふるくん（古里健太さん）からいただいた引き継ぎ一式です。
**2026/10/26 にまーく様からお預かりし、記録用スプシに合わせて手を入れました。**

---

## これは何か

- **ブラウザで動く、つけ待ちの台帳**です。スマホでもパソコンでも開けます。
- 記録用スプシと同じことが、ここでもできます（確認・入力・直す・消す）。
- **止まりません。** Google Apps Script のような「1日90分まで」の縛りがありません。

## 「いまアツい」の画面（2026/10/28 追加）

**まーく様のご指示（2026/10/27）**
> 大阪タクシー狙い目エリアで リアルタイムでの人の集中してるところを
> 割り出して 今はここがアツいポイントを、手軽にわかりやすく
> 可視化できるようにしてください

### 出しているもの

- **いまの時刻・いまの曜日**に、強かった場所を上から3つ
- このあと3時間、1時間ごとの見当
- 天気（**気象庁の公開データ**・無料・登録なし）

### 出していないもの（ここが大事）

- **「いま何人いるか」は出していません。**
  自分たちの記録からの傾向です。画面にも、そう書いてあります。
- **3件より少ない場所は出しません。** 1件は、たまたまの1本なので、
  平均と呼べません（`CLAUDE.md`「数字を出すときの決まり」）。

### 仕組み（直すときのために）

| 何 | どこ |
|---|---|
| 計算と画面 | `app.js` の「いまアツい（ここから）」〜「（ここまで）」 |
| 見た目 | `style.css` のいちばん下 |
| 押すところ | `index.html` の `data-t="hot"` |
| わざと壊して試すもの | `gas/test/hot.test.js`（`node gas/test/hot.test.js`） |

- 夜の種類を **金土／日／平日** に分けています。終電後の動きが違うためです。
- **昼や朝に開いたときは、きょうの夜（18時台）の見当にそろえます。**
  そうしないと「記録が足りません」しか出ず、見ても役に立ちません。
- 天気が読めなくても、**場所の見当はそのまま出ます**。
  読めなかったことは、画面に小さく出ます（黙って消えません）。

### お金

- **かかりません。** 気象庁の公開データは無料・登録なしで、
  そのままブラウザから読めます。
- 読みにいくのは **30分に1回** だけです。

## スプシから移す手順

① 記録用スプシ →「**説明**」タブ
② 「**[22] つけ待ち台帳用に書き出す**」に ☑ を入れる
③ 結果らんに「〇件を書き出しました」と出る
　 → まーく様のドライブに「つけ待ち台帳_261026.csv」という名前で入ります
　 （**共有はしていません。まーく様だけが見られます**）
④ そのファイルを開いて、**中身をすべてコピー**
⑤ つけ待ち台帳（ウェブ）→「**取り込み**」に貼る
⑥ 「読み取る」→ 中身を確かめて「取り込む」

**つまずきやすいところ**
- 同じ記録が2回入らないよう、アプリ側が見分けます（日付・時刻・金額が同じもの）。
- 「記録者」の名前がアプリの人と結びつかないときは、取り込んだ人のものになります。
  先に「管理」画面で、人の表示名をスプシのタブ名（ﾀﾞｲｽｹ・ｼｭﾝ…）に合わせておくと確実です。

## 公開するまで（まーく様の手が要るところ）

**これだけは、こちらからはできません。** アカウントを作る作業が入るためです。

`docs/01_セットアップ手順書.html` を開いて、書いてあるとおりに進めてください。
**パソコンで40分ほど**。黒い画面（コマンド）は使いません。

おおまかな流れ
1. **Supabase**（データの置き場）にアカウントを作り、プロジェクトを1つ作る
2. `supabase/schema.sql` の中身を、Supabase の SQL Editor に貼って Run
3. `config.js` の2行を、自分のプロジェクトの値に書き換える
4. **Vercel**（公開する場所）にアカウントを作り、このフォルダを置く
5. 人を招く（ログインできるようにする）

## お金のこと（いちばん大事）

**どちらも無料のまま使えます。** ただし、気をつけることが2つあります。

- **Supabase の無料プラン**
  - データは 500MB まで。乗務記録なら何年ぶんでも入ります。
  - **7日間まったく開かないと、いったん止まります**（消えません。開けば戻ります）。
    毎晩お使いになるので、ふだんは起きません。
- **Vercel の無料プラン（Hobby）**
  - 個人で使うぶんには無料です。

**お金のかかる設定は、どちらも こちらからは入れていません。**
使いすぎても請求は出ません（止まるだけです）。

## 鍵のこと

- `config.js` に書くのは「**公開してよい値**」です（ブラウザに必ず載るので、隠す意味がありません）。
- データは `schema.sql` の **RLS** で守っています。
- **`service_role key` は、絶対にここに書かないでください。** これは隠す必要のある鍵です。
